# v0.5.0 Release Notes

v0.5.0 makes the phone bridge recover from temporary network and app-server interruptions, refreshes the browser UI with a quieter Codex-inspired visual system, and introduces an installable Android client.

## Android APK

- `EasyCodex-v0.5.0.apk` is an installable Android 8.0+ client for the existing desktop bridge.
- First launch accepts the complete tokenized URL printed by `npm run phone`; the connection is retained only on the device and excluded from backup.
- A compact native toolbar provides reload and connection editing without exposing the token in its title.
- The WebView supports LAN HTTP, JavaScript, WebSocket recovery, image/file selection, downloads, safe browsing, and automatic reload after network restoration.
- The APK is release-signed. Keep the signing key used for v0.5.0 to preserve Android update compatibility.

The APK does not run Codex on the phone. Keep `npm run phone` running on the desktop and connect both devices to the same trusted LAN.

## Connection Reliability

- Browser WebSockets reconnect automatically with bounded backoff instead of requiring a manual relink.
- Online/offline transitions and mobile background-to-foreground recovery now trigger a clean bridge recovery.
- Heartbeats and a disconnect grace period reduce false disconnects while preserving real failure detection.
- Missing rollout data no longer prevents an otherwise valid empty thread from opening.
- Background polling pauses while offline and resumes after connectivity returns.

## UI And Branding

- Light and dark themes now use a calmer neutral palette, blue interaction accents, smoother surfaces, and more consistent mobile spacing.
- Mobile settings and theme switching have been corrected and polished.
- The supplied EasyCodex mark now appears in browser favicons, PWA icons, Apple touch icons, Android launchers, and the Android connection screen.

## Validation

- `npm run check`
- `npm test`
- `npm run docs:build`
- `npm run android:debug`
- Signed APK inspection with Android `aapt` and `apksigner`
- Browser offline/online recovery with Playwright at desktop and mobile viewport sizes
