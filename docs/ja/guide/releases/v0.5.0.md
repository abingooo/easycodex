# v0.5.0 リリースノート

v0.5.0 では、一時的な network / app-server 切断から phone bridge が自動復帰するようになりました。browser UI は Codex に近い落ち着いた配色と滑らかな操作感に更新され、インストール可能な Android client も追加されています。

## Android APK

- `EasyCodex-v0.5.0.apk` は Android 8.0 以降で利用できる既存 desktop bridge 用 client です。
- 初回起動時に `npm run phone` が表示する token 付き URL 全体を入力します。接続先は端末内だけに保存され、backup 対象にはなりません。
- compact な native toolbar から再読み込みと接続先変更を行えます。toolbar の表示には token を含めません。
- WebView は LAN HTTP、JavaScript、WebSocket recovery、画像・file 選択、download、safe browsing、network 復帰後の自動 reload に対応します。
- APK は release key で署名されています。Android update compatibility を維持するため、v0.5.0 で使用した signing key を保管してください。

APK 単体で phone 上に Codex を起動するものではありません。desktop で `npm run phone` を実行したまま、両端末を同じ信頼できる LAN に接続してください。

## Connection Reliability

- browser WebSocket は bounded backoff で自動 reconnect し、手動で再接続する必要を減らしました。
- online / offline 遷移と mobile app の background 復帰時に bridge recovery を実行します。
- heartbeat と disconnect grace period により短い切断の誤検知を抑えます。
- rollout data がない空 thread も正常に開ける fallback を追加しました。
- offline 中は background polling を停止し、接続復帰後に再開します。

## UI And Branding

- light / dark theme を neutral palette、blue accent、滑らかな surface、統一した mobile spacing に更新しました。
- mobile settings と theme switch の動作を修正しました。
- 提供された EasyCodex mark を favicon、PWA icon、Apple touch icon、Android launcher、Android 接続画面に適用しました。

## Validation

- `npm run check`
- `npm test`
- `npm run docs:build`
- `npm run android:debug`
- Android `aapt` / `apksigner` による signed APK inspection
- Playwright desktop / mobile viewport での offline / online recovery
